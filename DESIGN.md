# Zero Bounce — дизайн-система

## Идея: чертёж клиентского пути

Zero Bounce — бутиковое агентство, внешний отдел интернет-маркетинга для производителей интерьерных решений. Его философия — «архитектура клиентского пути»: клиент проходит пять этапов и не уходит (zero bounce — ноль отказов).

Интерьерная отрасль говорит языком чертежей: планы, штриховки материалов, размерные линии, штамп листа. Сайт оформлен как чертёж, по которому агентство «проектирует» путь клиента.

**Главный герой — фиолетовая точка.** Это клиент. Она падает в «О» в первом экране и останавливается без отскока, затем при прокрутке проходит по плану из пяти комнат-этапов. Фиолетовый цвет есть только у точки и у активных состояний — больше нигде.

## Цвета

| Токен      | Значение  | Роль                                           |
| ---------- | --------- | ---------------------------------------------- |
| `paper`    | `#EEF0EC` | основной фон — калька, холодный светло-серый   |
| `sheet`    | `#FFFFFF` | вставки поверх кальки: поля формы, плашки      |
| `ink`      | `#000000` | текст, линии чертежа, кнопки                   |
| `graphite` | `#5E625F` | второстепенный текст, подписи, размерные линии |
| `hatch`    | `#B9BDB7` | штриховка, тонкие разделители                  |
| `visit`    | `#5A3FF0` | точка-клиент, активные состояния, фокус        |

Тёмный «ночной лист» (калькулятор): фон `ink`, линии и текст `paper`.

## Шрифты

- **Unbounded Variable**, 200–300 — крупные заголовки. Тонкий широкий рисунок повторяет логотип. Жирно не используется.
- **Onest Variable**, 400/500 — текст, интерфейс, цифры (табличные).

Шкала (rem): 0.875 · 1 · 1.125 · 1.375 · 1.75 · 2.5 · 3.5 · 5. Текст — до 70 знаков в строке, межстрочный 1.55.

## Сетка и приёмы

- Выравнивание по левому краю, 12 колонок, поля 16 → 40 px.
- Разделители — тонкие линии чертежа, а не карточки с тенями.
- Штриховка (45°) — в «О»-мишени, на наведении в списке услуг, в образцах материалов.
- Цифры оформлены размерными линиями с засечками.
- Подвал — штамп чертежа: организация, реквизиты, лист.
- Кнопки — капсулы (как точка), чёрные; вторичная — контурная.

## Движение

Только три момента, остальное статично:

1. Падение точки в «О» при загрузке (один раз, ≈1.2 с).
2. Путь точки по плану — управляется прокруткой.
3. Отклик на действия: пересчёт калькулятора, раскрытие меню и вопросов.

`prefers-reduced-motion`: точка сразу на месте, путь показывает этапы без движения.

## Запреты

Капслок-подписи над заголовками, разноцветное слово в заголовке, «→» в кнопках, моноширинные подписи, карточки с одинаковыми тенями, нумерация там, где нет последовательности.
